# Aulas de Python - Udemy

Este repositório reúne códigos e exercícios desenvolvidos durante as aulas de um curso de Python da Udemy. Os arquivos estão organizados em sequência (`aula1.py`, `aula2.py` e assim por diante) e registram exemplos e práticas realizados ao longo do aprendizado.

## Como executar

Tenha o Python 3 instalado e, no terminal, execute o arquivo da aula que deseja consultar:

```bash
python aula1.py
```

Alguns exemplos solicitam dados pelo terminal; basta seguir as instruções exibidas pelo programa.

## Organização

- `aula1.py` a `aula33.py`: exemplos e exercícios das aulas.
- `.vscode/launch.json`: configuração de execução e depuração no Visual Studio Code.

Os códigos têm finalidade educacional e podem ser modificados para experimentar os conceitos estudados.
